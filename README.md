# Доски проектов

Бесконечный холст для идей, проектов и командной работы. Работает офлайн, ставится как приложение
на Windows и Android, данные хранятся в вашем приватном репозитории GitHub, правки команды видны мгновенно.

**Приложение:** https://naito33.github.io/boards-app/

## Управление

| Действие | Как |
|---|---|
| Выделить карточку | клик; ещё клик — редактировать текст; Enter — начать редактирование |
| Выделить несколько | рамкой по пустому месту, Shift+клик, Ctrl+A |
| Двигать | тянуть за любое место карточки; стрелки — сдвиг (Shift — на 10) |
| Размер | ручки по краям выделения (у разделов, рисунков, приложений — и высота) |
| Зум | колесо мыши (плавно, без Ctrl), щипок на тачпаде/телефоне, + / − |
| Двигать холст | пробел + мышь, средняя или правая кнопка, инструмент «Рука», палец на телефоне |
| Меню | правый клик (на телефоне — долгое нажатие) |
| Копировать / вставить карточки | Ctrl+C / Ctrl+V (работает между досками) |
| Отмена | Ctrl+Z / Ctrl+Shift+Z |
| Показать всё / выделенное | Shift+1 / Shift+2 |

**Инструменты:** V — выделение, H — рука, P — карандаш, A — стрелка (связь карточек, а от карточки в пустоту — новый стикер),
I — пин, R — верёвка (между пинами/карточками, пины ставятся сами, верёвки провисают и покачиваются).
Пин на карточке двигается вместе с ней. N — стикер, T — заметка, F — раздел, Ctrl+G — объединить выделенное в раздел.
Удаление раздела удаляет всё, что в нём (можно отменить).

**Текст (кнопка «Aa»):** 8 шрифтов (обычный, рукописный как в tldraw, с засечками, моноширинный, округлый, акцентный, узкий, каллиграфия), размер, жирный, курсив, подчёркнутый, зачёркнутый, выравнивание, цвет, межстрочный интервал. В заметке стиль можно применить к выделенному фрагменту.
**Картинки:** по умолчанию без подложки (в настройках можно вернуть), кнопка «Обрезать».
**Лупа** (меню «+» → «Лупа»): увеличивает то, что под ней, с эффектом «рыбьего глаза»; увеличение и сила искажения — на панели.
**Кнопки-ссылки** (меню «+» → «Кнопка-ссылка»): клик — переход на доску или сайт, тянуть — переместить, правый клик — изменить.
**Поддоски:** путь «Родитель › Доска» в шапке, окно «Структура досок», в списке проектов — сворачивание и «Скрыть поддоски», ⋯ → «Сделать поддоской…». Доска без родителя, на которую сослались, становится поддоской.
**Ещё:** поворот карточек (кружок над выделением, Shift — по 15°), замок, выравнивание и распределение нескольких карточек.
**Импорт tldraw:** шрифты и размеры как в tldraw, выравнивание, поворот, обрезка фото, страницы выстраиваются в дерево по ссылкам.
**Важность карточек:** клавиши 1 — «Необходимо», 2 — «Менее важно», 3 — «Не нужно», 0 — снять (или кнопка ✓ на панели).
«Сортировка по важности» (правый клик по холсту или меню фигур) создаёт зоны и раскладывает карточки; перетащили карточку в зону — оценка поменялась сама.
«Скрыть «Не нужно»» — в меню правого клика.
**Подпись над карточкой** («Заметка», «Референс»…): двойной клик — переименовать; «⋯» → скрыть; в настройках — скрыть у всех.
**Пин и верёвка** — один инструмент (I): нажали — пин, протянули — верёвка.
**Музыка с эквалайзером:** «Приложения» → «Свой трек» или перетащите mp3 на холст — 5 полос, пресеты, визуализатор.
Встроенные Spotify/YouTube/Яндекс Музыка играют сразу по кнопке, но эквалайзер к ним применить нельзя — браузер не даёт доступа к их звуку.
**Изгиб:** выделите стрелку или верёвку — потяните синюю точку посередине (двойной клик — сбросить). На панели: наконечники, пунктир, подпись, «выпрямить».
**Подложка:** заметку и картинку можно сделать без подложки (просто текст / просто фото) — кнопка «Без подложки»; T — сразу текст без подложки.
**Ссылки:** у любой карточки кнопка 🔗 — ссылка на сайт, другую доску или новую вложенную доску; «←» в шапке — назад.
**Диаграммы (D):** блок-схемы (Tab в фигуре — следующий шаг), майнд-карты (Tab — ветка, Enter — соседняя идея),
диаграммы: столбцы, линия, области, круговая, кольцо, радар, спидометр — из своих данных или автоматически из задач; таймлайн задач (Гант).
**Импорт tldraw:** каждая страница — отдельная вложенная доска, ссылки между страницами и фигурами работают, текст и фото — без подложек, стрелки — с изгибом и подписями.

## Возможности
- Карточки: заметка, стикер, чек-лист, канбан, прогресс-бар, дедлайн, таймер, референс, ссылка, палитра, заголовок, раздел.
- **Приложения:** вставьте ссылку (Ctrl+V или кнопка «Приложения») — YouTube, Rutube, Vimeo, Spotify, Яндекс Музыка,
  SoundCloud, Apple Music, пины Pinterest, Figma, Google Docs/Таблицы/Слайды, Miro, Google Карты встраиваются прямо на доску.
  Картинки из Pinterest и других сайтов можно перетаскивать из браузера.
- **Палитры:** случайная гармония, от своего цвета (6 схем), из картинки, по настроению (ИИ); закрепление цветов, обновление, копирование в CSS.
- **Вдохновение:** SCAMPER, шесть шляп, Crazy 8s с таймером, обратный штурм, случайные ассоциации, вопросы-подсказки,
  командный таймер, поиск референсов на Pinterest/Behance/Dribbble/Unsplash/Are.na.
- **ИИ-помощник (Claude):** анализ доски (итог, риски, шаги), идеи стикерами, «что упущено», разбивка на задачи со сроками,
  ответы на вопросы о доске; видит и картинки-референсы. Нужен свой ключ API (console.anthropic.com), хранится только на устройстве.
- **Команда:** имена, голосование, обсуждения карточек, активность, задачи с исполнителями и сроками, живые курсоры.
- **Импорт из tldraw:** файл `.tldr` (меню проектов → «Импорт» или перетащить на холст).

## Синхронизация
- **Хранилище:** приватный репозиторий GitHub (`boards/*.json`, `images/*`). Сохранение — через несколько секунд после правки,
  проверка чужих изменений — каждые 4 секунды (бесплатно, не тратит лимит GitHub).
- **Реальное время:** когда участники открыли доску одновременно, устройства соединяются напрямую (WebRTC) —
  правки, перетаскивание и курсоры видны мгновенно. Для знакомства устройства обмениваются зашифрованными сообщениями
  через публичный сервис ntfy.sh; ключ шифрования лежит в вашем репозитории (`realtime.json`). Отключается в настройках.
  Если прямое соединение невозможно (бывает в некоторых мобильных сетях), изменения приходят через GitHub за несколько секунд.

## Настройка
1. Приватный репозиторий `boards-data`, токен: github.com/settings/personal-access-tokens → Fine-grained → только `boards-data` → Contents: Read and write.
2. В приложении: ☰ → «Настройки» → имя, владелец (логин GitHub), репозиторий, токен; при желании — ключ Claude.
3. Команда: участники добавляются в `boards-data` (Settings → Collaborators) и вводят свой токен.
