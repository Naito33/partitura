# Доски проектов

Бесконечный холст для проектов, вдохновения и командной работы. Работает офлайн, ставится как приложение
на Windows и Android, синхронизируется через ваш приватный репозиторий GitHub — без собственного сервера.

## Возможности

**Карточки** (панель внизу или двойной клик по фону)
- Заметка — форматирование, списки («- » в начале строки)
- Стикер — быстрая идея, 8 цветов
- Чек-лист — пункты со сроком и исполнителем, собственный прогресс
- Канбан — колонки «Надо сделать / В работе / Готово», задачи двигаются стрелками ← →, у задач срок и исполнитель
- Прогресс-бар — вручную или автоматически по всем задачам доски / конкретному чек-листу или канбану
- Дедлайн — обратный отсчёт дней, подсветка «скоро» и «просрочено», шкала прошедшего времени
- Референс — картинки из буфера (Ctrl+V), перетаскиванием или из галереи; кнопка 🎨 извлекает из картинки палитру
- Ссылка, Палитра (копирование HEX по клику, случайная гармоничная палитра), Заголовок
- Раздел — область для группировки: при перетаскивании двигает все карточки внутри
- Стрелки-связи между карточками (кнопка → на карточке, затем клик по второй; клик по стрелке — удалить)

**Вдохновение** (кнопка ✦)
- Вопрос-подсказка — стикер со случайным творческим вопросом (25 вариантов)
- Случайная палитра
- Сессия мозгового штурма — раздел с 4 вопросами и местом для идей

**Управление проектами**
- Шаблоны новых проектов: пустая доска, мудборд, управление проектом, мозговой штурм, спринт
- Панель справа → «Задачи»: все задачи доски из чек-листов и канбанов, фильтры «Открытые / Мои / Просрочено / На неделе / Готово», отметка выполнения прямо из списка
- Список проектов (☰) с прогрессом и количеством задач
- Поиск по всем проектам, карточкам и комментариям — Ctrl+K
- Отмена/повтор — Ctrl+Z / Ctrl+Shift+Z (или кнопки внизу), Ctrl+D — дублировать, Del — удалить

**Команда**
- Имя участника (в настройках) — подписывает правки, видно на карточках и в шапке доски
- 👍 голосование за карточки, 💬 обсуждение каждой карточки
- «Активность» — лента изменений: кто, что и когда сделал
- Исполнители задач с подсказками по именам участников
- Одновременные правки сливаются по карточкам; голоса и комментарии разных людей не затирают друг друга

**Интерфейс** — светлая и тёмная тема, стеклянные панели, адаптация под телефон (щипок для масштаба).

## Где хранятся данные

| Где | Что |
|---|---|
| На устройстве (IndexedDB браузера) | Все доски и картинки — работает без интернета |
| Приватный репозиторий GitHub | `boards/<id>.json` — по файлу на доску, `images/<hash>.webp` — референсы |

GitHub бесплатен, не требует сервера и хранит историю всех версий. Синхронизация идёт сама
(через 4 с после правки, раз в минуту, при сворачивании/открытии); кнопка ⟳ — синхронизировать сейчас.

## Установка

### 1. Выложить приложение (GitHub Pages)
1. Создайте **публичный** репозиторий, например `boards-app` (только код, без данных).
2. Загрузите `index.html`, `sw.js`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png`.
3. *Settings → Pages → Deploy from a branch → main / (root)*. Адрес: `https://<логин>.github.io/boards-app/`.

### 2. Хранилище
1. Создайте **приватный** репозиторий `boards-data` (с README).
2. Токен: *Settings → Developer settings → Personal access tokens → Fine-grained* → только `boards-data` →
   *Contents: Read and write*.

### 3. Устройства
- Windows: откройте адрес в Edge/Chrome → «Установить приложение» в адресной строке.
- Android: Chrome → ⋮ → «Установить приложение».
- В приложении: ☰ → «Синхронизация и команда» → имя, владелец, репозиторий, токен.

### 4. Команда
1. Владелец `boards-data`: *Settings → Collaborators → Add people*.
2. Каждый участник ставит приложение по тому же адресу и в настройках указывает **тот же** репозиторий
   (владелец — логин владельца) и **свой** токен:
   - если репозиторий в личном аккаунте другого человека — classic-токен со scope `repo`;
   - удобнее создать бесплатную **организацию** GitHub и держать репозиторий там — тогда всем подходят fine-grained токены.

Токен хранится только на устройстве и отправляется только на api.github.com.
