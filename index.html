Настройки

Синхронизация — приватный репозиторий GitHub

  1. Приватный репозиторий (например boards-data).
  2. Токен: github.com/settings/personal-access-tokens → Fine-grained → только этот репозиторий → Contents: Read and write.

Устройства соединяются напрямую. Для знакомства они обмениваются зашифрованными сообщениями через публичный сервис ntfy.sh; ключ шифрования хранится в вашем репозитории.

ИИ-помощник (Claude)
