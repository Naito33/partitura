Синхронизация и команда

Хранилище — приватный репозиторий GitHub

  1. Создайте приватный репозиторий (например boards-data).
  2. Создайте токен: Settings → Developer settings → Personal access tokens → Fine-grained → только этот репозиторий → Contents: Read and write.

Работа в команде

Владелец добавляет людей в репозиторий: Settings → Collaborators. Каждый участник вводит здесь тот же репозиторий и свой токен. Если репозиторий принадлежит другому человеку, нужен classic-токен со scope repo. Если репозиторий лежит в организации GitHub, подойдёт и fine-grained.
